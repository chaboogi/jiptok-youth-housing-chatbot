# 집톡 (Jiptok)

청년 주거지원 정책 맞춤 안내 및 학습형 AI 챗봇

청년이 자신의 조건에 맞는 주거지원 정책을 찾고, 정책 이해에 필요한 개념(기준 중위소득, LTV, 청약 등)을 챗봇과의 대화와 퀴즈로 학습할 수 있도록 설계한 웹 애플리케이션입니다. Google AI Studio의 Build 기능을 활용해 구조화된 프롬프트로 개발하였습니다.

## 주요 기능

| 단계 | 내용 |
|------|------|
| 1단계 기본 정보 | 나이, 거주 지역, 주거 상황을 버튼으로 선택 |
| 2단계 소득 정보 | 소득 경로, 월 소득, 부모님과의 독립 여부 선택 |
| 3단계 맞춤 정책 추천 | 입력 조건에 따른 정책 카드 제시, 조건 충족 여부 배지(내 조건에 해당 / 조건 확인 필요) 표시 |
| 4단계 상세 안내와 학습형 챗봇 | 정책 상세 표, 중위소득 대비 내 소득 비율 안내, 정책별 빠른 질문 버튼, 학습형 챗봇 |

### 학습형 챗봇 흐름

1. 사전 지식 수준 선택(처음 알아보는 중 / 어느 정도 앎 / 잘 앎)에 따라 설명 깊이와 퀴즈 난이도 조절
2. 개념 설명 후 꼬리질문으로 이해 수준 확인
3. 객관식 또는 OX 퀴즈 출제와 해설
4. 대화 종료 시 학습 요약(배운 개념, 퀴즈 결과, 한 줄 정리, 추천 다음 단계) 제공

### 안내 대상 정책

청년월세지원(서울시), 국토부 청년월세 특별지원, 청년 버팀목 전세자금 대출, 행복주택, 청년안심주택, 청년 매입임대주택, 한국장학재단 주거비 지원

## 개발 과정

| 버전 | 주요 변경 사항 |
|------|---------------|
| v1.0 | 4단계 흐름(조건 입력, 정책 추천, 상세 안내, 챗봇)의 기본 프로토타입 |
| v2.0 | 단순 질의응답을 넘어 학습 도구가 되도록 꼬리질문, 퀴즈, 학습 요약 기능 추가 |
| v3.0 | 사용성 평가 결과 반영: 지식 수준 선택, 정책별 빠른 질문 버튼, 조건 충족 배지, 소득 비율 안내, 설명 분량 확대, 직접 입력 질문의 요약 포함 |

## 사용성 평가

v2.0을 대상으로 평가자 3명이 유용성, 효율성, 효과성, 만족도 4개 영역 16개 문항(5점 척도)을 평가하였습니다.

- 전체 평균: 4.69 / 5.00
- 만족도: 5.00 / 5.00
- 개선 요구 사항(서비스 정체성, 개인화된 정책 표시, 챗봇 학습 깊이)을 v3.0에 반영

## 기술 구성

- Frontend: React, TypeScript, Vite, Tailwind CSS
- Backend: Express (`server.ts`)
- AI: Google Gemini API (`@google/genai`), 서버에서만 호출하여 API 키를 클라이언트에 노출하지 않음
- API 호출이 불가능한 경우 내장 학습 데이터(`src/data/curriculum.ts`)로 응답

## 로컬 실행

```bash
npm install
cp .env.example .env   # .env 파일에 GEMINI_API_KEY 입력
npm run dev            # http://localhost:3000
```

## 유의 사항

정책 정보는 개발 시점 기준이며 실제 지원 조건과 금액은 변경될 수 있습니다. 신청 전에는 각 기관의 공식 공고를 확인해야 합니다.
